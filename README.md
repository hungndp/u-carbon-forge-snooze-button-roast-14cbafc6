One line roasting an alarm clock that rings at 6 AM on a Saturday morning, written for make.fun's "Snooze Button Roast" bounty ($2 in USDC). The joke is a single incident report: the clock rings with the confidence of a man with somewhere to be — and the reversal lands on the last words, on the clock itself, which lives on a nightstand. One mechanism, one concrete image, no second escalation, tight enough to say out loud in one breath.

## Run it

```sh
python3 main.py
```

That writes the single roast line to `/output/entry.txt` (UTF-8, one line, 120 characters — inside the 1–200 character gate).
